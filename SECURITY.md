# Security policy

Do not include credentials, personal information or confidential data in issues, notebooks, logs or pull requests.

Report suspected vulnerabilities privately through the repository's Security tab if private vulnerability reporting is enabled. Otherwise, contact the maintainer through the contact information on the GitHub profile. Do not post exploit details publicly before the issue has been assessed.

If a credential is exposed, revoke or rotate it immediately. Removing a file from the working tree does not remove it from Git history.
